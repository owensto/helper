# ATLAS D 272

Dual-domain luxury surface-yacht / submersible visualization concept.

Locked concept envelope:
- LOA: 82.9 m / 272 ft
- Beam: 14.2 m
- 12 guests, 20–24 crew concept
- Surface-yacht and submerged visual states
- Conceptual pressure-hull, ballast, propulsion, energy, life-support, mission-bay and retractable-system visualization

This repository work is visualization only. It is not naval architecture, construction data, pressure-vessel engineering, life-safety design, or operational guidance.

Build goal: a Blender-generated master plus a browser GLB with interactive SURFACE / DIVE / X-RAY states and camera presets.
