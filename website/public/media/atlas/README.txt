Castward atlas geographic data

Base map: Natural Earth 1:110 million, distributed as world-atlas 2.0.2 TopoJSON.
Source: https://github.com/topojson/world-atlas
Downloaded 2026-11-10 from https://cdn.jsdelivr.net/npm/world-atlas@2.0.2/countries-110m.json
Natural Earth geographic data is in the public domain.
https://www.naturalearthdata.com/about/terms-of-use/

Location references: OpenStreetMap contributors, ODbL 1.0.
https://www.openstreetmap.org/copyright
Approximate place and region reference points, not access or navigation coordinates.
The location source register is published at /media/atlas/locations.json.

The browser uses only self-hosted data. No tile provider, geocoding request or API key is needed.
D3 and TopoJSON client licenses: /media/atlas/LICENSES.txt
Rebuild the committed bundle: npm --prefix client ci && npm --prefix client run build

Supplementary location references: GeoNames (CC BY 4.0), USGS, Wikidata (CC0),
and the Pluma River field study in Agrion 20(2), 2015.
Each record names its source and any regional scope limit.
https://www.geonames.org/
