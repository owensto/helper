# Guide content and evidence flow

The release updates ten destination guides and six preparation articles. It adds five preparation articles. Existing URLs and trip IDs remain unchanged.

## One content source

`src/guides.json` stores authored sections, source references, comparisons, FAQs, related links and reel choices. Each source has a check date and scope. Section references form the claim-to-source ledger. The source status applies to inspected text, not a field test or operator review.

The destination records use existing trip IDs. The preparation articles use their existing or new `/guides/` slug. Each planner link uses an existing destination ID. A preparation article does not create a new destination or raise its evidence tier.

## Producers and consumers

| Boundary | Behavior |
| --- | --- |
| Official pages → authored records | Full text supports the attributed claims. Packing choices remain editorial advice. |
| `guides.json` → `compile_release.py` | The guide compiler updates ten existing records after the local trip-type additions. |
| Compiler → `world.json` | The catalog retains IDs, paths, trip types and images. It receives the current title, summary, evidence, sections and review date. |
| Catalog → search, regional cards and planner | Titles and preparation decisions use the compiled record. Planner equipment remains scoped to the same trip ID. |
| Catalog → seasonal register | Only explicit source-supported month windows appear. No monthly scores are inferred from broad seasons. |
| Guide renderer → destination pages | The authored article replaces the old article body at its canonical route. The old renderer is not an additional public article. |
| Guide renderer → preparation pages | The same renderer supplies comparisons, sources, related links and planner calls to action. |
| FAQ records → HTML and FAQPage | Both outputs use the same question and answer records. |
| Page metadata → Article and sitemap | Updated pages use 2026-11-10. New articles also use that publication date. Other pages keep their existing dates. |
| `videos.json` → guide reel | The shared video renderer uses the existing media and captions. A related location is identified in the visible note. |
| Hub → discovery | The hub links all 40 source-checked destination records and 11 preparation articles. The two scoped overview pages keep noindex. |
| Existing consent analytics → planner | Existing guide/trip view and planner-start events continue. No booking or sale event is fabricated. |

The six preparation articles previously lived only in `build.py`. The final guide renderer now uses their authored records. Legacy article definitions remain for the older preview construction; they do not determine the published guide bodies. The README and historical release counts describe older releases. The current compiled catalog contains 798 profiles and 40 source-checked destinations.

## Evidence limits

The demand order is an editorial estimate from destination recognition, trip intent and practical decisions. No verified keyword-volume dataset or Search Console export was available.

The Lake Fork limit endpoint returned HTTP 500. The guide links the official lake page and Outdoor Annual. The Situk date widget contains malformed values. The guide uses the written sockeye timing and states the coho calendar gap.

Charleston County Parks blocked the shell fetch. The web tool opened and displayed the full official landing page and closure notice. The notice dates to 4 November 2026. It describes a planned closure and expected reopening, not a completed event.

The Coast Guard newsroom blocked access. An official Coast Guard bulletin on its government delivery service supplied the passenger-check guidance. Its 2022 publication date remains visible in the source scope.

No exact destination film exists for six of the ten updated trips. These guides use a related animation with a clear location or technique limit. No new media or catch evidence is claimed.

The raw fetch receipts, original audit pages and final result report are in the sibling `seo-reports/runs/castward-guides-20261110/` workspace. The public source lists identify the facts a reader must recheck before travel.
